# Worktual Ticketing

Connect Cursor to Worktual Ticketing. Staff can look up customers, review and create tickets, and draft knowledge-base articles through the signed-in Worktual account.

The server address is `https://ticketing-mcp.worktual.com/mcp`.

## Install

1. Install this plugin from the Cursor Marketplace, or add the server URL in Cursor under **Customize → MCPs**.
2. Turn **worktual-ticketing** on.
3. Sign in at `https://oauth.worktual.com` with a Worktual staff account.
4. Choose the Worktual organization.

Admin and Agent accounts can use every tool. Resolver accounts can look up customers and tickets and add notes.

No API key or client secret is required. Cursor registers itself and signs in with your Worktual account.
